# 나만의 서재 📚

내가 읽은 책을 한 권씩 모으는 모바일 독서 관리 웹앱입니다. 서버도, 로그인도, 빌드도 필요 없습니다.
`index.html`을 열면 바로 동작하고, GitHub Pages에 올리면 폰 홈 화면에 앱처럼 설치할 수 있습니다.

## 화면

- **서재 보기** — 3열 표지 그리드, 카테고리 칩(전체 / ❤️ / 소설 / 인문 / …), 읽기 상태 칩(전체 / 완독 / 중단 / 읽는 중), 제목·저자·한 줄 평·문구 실시간 검색
- **책 등록/수정** — 제목만 넣고 `🔍 표지·저자 찾기`를 누르면 저자·표지·분야가 자동으로 채워집니다. 읽기 시작한 날짜와 끝난 날짜, 읽기 상태(완독 / 중단(포기) / 읽는 중)를 함께 기록합니다
- **책 상세** — 큰 표지, 제목·저자, 카테고리·읽은 기간(`2026-09-10 ~ 2026-09-17 완독`)·하트 칩, 한 줄 평, 💬 마음에 든 문구(추가·수정·삭제), 수정 / 삭제
- **마음에 든 문구** — 책마다 여러 개 저장. 페이지 번호는 선택, 인용 카드로 보이고 개별 수정·삭제 가능. 검색창에서 문구 내용으로도 책을 찾음
- **독서 통계** — 총 완독 / 올해 완독 / ❤️ 하트, 연도별·월별 완독 막대, 카테고리 분포(%). 중단·읽는 중인 책은 완독 통계에 넣지 않고 따로 작게 보여줍니다
- **데이터 복사 & 이동** — JSON으로 서재 전체를 복사하고, 다른 브라우저로 옮기거나 백업

## 파일 구성

```
reading-app/
├─ index.html              화면 구조
├─ styles.css              스타일 (모바일 우선, 다크모드 없음)
├─ app.js                  화면 동작 · 저장 · 병합
├─ core.js                 데이터 로직 (파싱/병합/통계) — DOM 없이 동작
├─ books.json              공용 서재 데이터 (책 목록)
├─ covers/                 샘플 책 표지 이미지
├─ manifest.webmanifest    PWA 설정 (홈 화면 추가)
├─ sw.js                   오프라인 캐시
├─ icon.svg                앱 아이콘 (벡터)
├─ icons/                  앱 아이콘 PNG 192/512/maskable/apple-touch
└─ .nojekyll               GitHub Pages가 파일을 그대로 올리도록
```

## 배포하기 (GitHub Pages)

1. GitHub에서 새 저장소를 만듭니다(공개 저장소면 무료 Pages 사용 가능).
2. 이 폴더의 파일을 **폴더째** 올립니다. (웹 화면에서 드래그하거나, 아래 명령)

   ```bash
   cd reading-app
   git init
   git add .
   git commit -m "나만의 서재"
   git branch -M main
   git remote add origin https://github.com/<아이디>/<저장소>.git
   git push -u origin main
   ```

3. 저장소 **Settings → Pages** 에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)` 로 저장합니다.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/` 주소로 열립니다.

> 저장소를 비공개로 두면 무료 계정에서는 Pages가 열리지 않습니다. 공개 저장소를 쓰거나
> Netlify Drop(<https://app.netlify.com/drop>)에 이 폴더를 끌어다 놓아도 그대로 배포됩니다.

## 폰에 앱처럼 설치하기

- **안드로이드 크롬 / 삼성 인터넷**: 주소창 오른쪽 메뉴 → `홈 화면에 추가` (또는 `앱 설치`)
- **아이폰 사파리**: 공유 버튼 → `홈 화면에 추가`

설치하면 주소창 없이 열리고, 한 번 열어둔 뒤에는 인터넷이 잠깐 끊겨도 화면이 뜹니다.

## 책 추가하는 두 가지 방법

**1) 앱에서 직접** — 오른쪽 위 `+ 책 등록` → 제목만 적고 `🔍 표지·저자 찾기`를 누르면 저자·표지·분야가 자동으로 채워집니다.
마음에 드는 후보를 누른 뒤 시작일·끝난 날짜·읽기 상태·한 줄 평을 넣고 저장합니다.
이 내용은 그 폰의 브라우저(`localStorage`)에 저장됩니다.

> 자동 검색은 인터넷이 필요하고, Google Books와 Open Library의 공개 데이터를 씁니다. 표지를 못 찾으면 파스텔 기본 표지가 그려집니다. 검색이 안 되면 채팅으로 책 제목을 알려주세요.

**2) `books.json`에 올리기** — 책 목록을 파일로 관리하면 여러 기기에서 같은 목록을 봅니다.
`books.json`의 `books` 배열에 책을 추가하고 GitHub에 올리면(`push`), 앱을 다시 열 때 자동으로 내려받아 보여줍니다.

```json
{
  "id": "chotdol",
  "title": "쇳돌",
  "author": "이라영",
  "category": "인문",
  "startDate": "2026-09-10",
  "endDate": "2026-09-17",
  "status": "완독",
  "cover": "covers/chotdol.jpg",
  "memo": "사라지는 노동의 목소리를 이렇게 오래 들여다볼 수 있다는 것.",
  "heart": true
}
```

- `id`는 책마다 겹치지 않게 (영문·숫자 아무거나). 한 번 정하면 바꾸지 않는 편이 좋습니다.
- `startDate` / `endDate`는 `YYYY-MM-DD`. 모르면 `""`. 예전처럼 `finishedAt`이나 `date` 하나만 있어도 **끝난 날짜**로 읽습니다.
- `status`는 `완독` / `중단` / `읽는 중`. 없으면 `완독`으로 봅니다.
- `cover`는 `covers/내표지.jpg` 같은 상대 경로나 `https://…` 주소. 비우면 기본 표지가 그려집니다.
- `heart`는 `true` / `false`.
- `quotes`는 마음에 든 문구 목록입니다(없으면 `[]`).

```json
"quotes": [
  { "id": "q-chotdol-1", "text": "사라지는 것은 사라지기 전에 이미 오래 울고 있었다.", "page": "42", "createdAt": "2026-11-14T07:20:00.000Z" }
]
```

- `page`는 선택. `"42"`, `"12-15"`처럼 쓰고, 앱에서 `p.42`처럼 보입니다.
- `id`가 겹치면 새로 붙여 읽으므로 문구를 손으로 추가할 때도 id만 다르면 됩니다.

## 데이터는 어떻게 저장되나요

- `books.json` = **모두에게 보이는 기본 목록**.
- 브라우저 `localStorage` = **내가 고친 내용·내가 등록한 책·내가 지운 책**만 따로.
- 앱을 열 때 두 가지를 **책 `id` 기준으로 합칩니다.** 그래서:
  - 내가 앱에서 고치거나 지운 책은 `books.json`이 바뀌어도 내 선택이 유지됩니다.
  - `books.json`에 새로 올라온 책은 내 폰에도 자동으로 나타납니다.
- 마음에 든 문구도 같은 방식으로 저장됩니다. 앱에서 단 문구는 `localStorage`에, `books.json`에 적어 둔 문구는 공용 목록에 남습니다.
  `데이터 복사하기`/`데이터 불러오기`에도 문구가 그대로 함께 옮겨집니다.
- 그래서 `books.json`에서 책을 지워도, 이미 그 책을 지운 적이 없는 기기에서는 그대로 남아 있을 수 있습니다.
  없애려면 앱에서 그 책을 삭제하면 됩니다.
- 저장 위치가 브라우저마다 다르기 때문에, **크롬에서 넣은 책은 삼성 인터넷에 자동으로 넘어가지 않습니다.**
  통계 탭의 `데이터 복사하기` → 다른 브라우저에서 `데이터 불러오기`로 옮기세요.
  (불러올 때 `기존 책을 모두 지우고 불러오기`를 고르면 샘플 책까지 깔끔하게 정리됩니다.)

## 개발 메모

- 외부 라이브러리 없음. `fetch('books.json')`은 캐시를 피하려고 `?t=시간`을 붙입니다.
- `core.js`는 화면과 분리되어 있어 브라우저 없이도 테스트할 수 있습니다(`module.exports` 지원).
- 샘플 책에는 `"sample": true`가 붙어 있고, 서재 위쪽 안내에서 한 번에 지울 수 있습니다.
- 서비스 워커는 앱 껍데기만 캐시하고 `books.json`은 항상 네트워크를 먼저 확인합니다.
  코드를 고친 뒤 폰에서 옛 화면이 보이면 `sw.js`의 `CACHE` 이름(`shelf-v3`)을 올리면 됩니다.
- 표지·저자 검색은 `books.google.com/books/feeds/volumes`(키 없이 CORS 허용)와 `openlibrary.org`를 함께 써서 결과를 합칩니다.
  Google Books의 `www.googleapis.com/books/v1`은 키 없는 요청이 하루 할당량 0으로 막혀 있어 마지막 순서로만 시도합니다.
  표지가 `image not available` 그림인 판본(id가 `CAAJ`로 끝나거나 `view_no_pages`)은 표지를 비워 파스텔 기본 표지를 그립니다.
