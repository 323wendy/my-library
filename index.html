    불러오는 방법

    ☁️ 기기 간 동기화

    폰과 PC에서 같은 기록을 함께 써요. 기록을 더하거나 고치면 GitHub 저장소의 books.json · videos.json · webtoons.json에 바로 저장되고, 다른 기기에서도 그대로 보여요.

    ☁️ 동기화 미연결

    🔑 GitHub에서 토큰 만들기 — 권한은 repo만 체크하면 돼요.

    토큰은 이 기기 브라우저에만 저장되고, 기록 데이터나 저장소에는 담기지 않아요.

    토큰은 이렇게 만들면 돼요
    1. 위의 GitHub에서 토큰 만들기를 누르면 새 토큰 화면이 열려요.
    2. repo 권한을 체크하고 아래쪽 Generate token을 눌러요.
    3. 나오는 ghp_… 값을 복사해 위 칸에 붙여넣고 동기화 연결 테스트 및 지금 동기화를 눌러요.
    4. 다른 기기에서도 한 번만 같은 방법으로 연결하면, 그때부터는 양쪽이 자동으로 맞춰져요.

    토큰을 끊고 싶으면 연결 해제를 누르면 돼요. 기록은 이 기기에 그대로 남아요.

    이 저장소는 공개 저장소라, 올린 기록(제목·한 줄 평·문구)은 누구나 볼 수 있어요. 공개하고 싶지 않으면 비공개 저장소를 하나 만들어 위 저장소 칸에 그 이름을 적으면 돼요.

    삭제할까요?

    삭제한 기록은 되돌릴 수 없어요.
